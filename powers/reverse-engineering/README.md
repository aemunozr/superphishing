# Reverse Engineering Power

Incluye la Skill `reverse-engineering` y conexiones MCP propias con Ghidra y Radare2. Elige solo las herramientas necesarias para responder la pregunta de análisis, evitando importar decompilados o salidas completas al contexto.

Credenciales: `GHIDRA_MCP_BASIC_AUTH` (Base64 de `usuario:contraseña`, sin el prefijo `Basic `) y `RADARE2_MCP_TOKEN` (solo el token Bearer, sin prefijo). Base64 es codificación reversible, no cifrado. No guardar secretos en este directorio.
